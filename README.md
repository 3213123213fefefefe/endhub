# EndHub Extras

Optional tools for the [main EndHub build](https://github.com/3213123213fefefefe/endhub/tree/main).

Open **Settings → Open Extras window** in EndHub. Do not run this branch as another bot: its loader receives the existing hub and shares that hub's farm/sale controller and settings.

Includes Boss, Mob Farm, manual movement, player tools, visuals/Trinket ESP, keybinds, farm tuning and seller diagnostics. Closing Extras via its Settings tab stops these tools and disconnects their listeners without unloading the main bot. Hiding the window leaves enabled tools running.

The main build pins a specific Extras commit to keep the two APIs compatible. The complete original build remains in [the backup branch](https://github.com/3213123213fefefefe/endhub/tree/backup-before-multi-instance-20260909).
